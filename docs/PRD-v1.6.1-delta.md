# PRD V1.6.1 修复说明（相对 V1.6）

- 版本：V1.6.1（2026-10-28）
- 问题：① 订单管理里「需求沟通」等节点无法选择当前进度状态；② 订单中录入的物料在「物料管理」中看不到

## 一、进度状态按钮失效的修复

- **原因**：V1.6 把四个状态按钮嵌在 `<Form.Item name="status">` 内的 `shouldUpdate` 子项里，
  按钮的取值/回填依赖表单上下文，实际点击不会写入表单值，导致保存的状态仍是原值
  （第一个节点默认「未开始」，看起来就是“选不了”）。
- **修复**：状态选择改为**独立受控状态**（`statusValue`），按钮直接读写该状态并在确定时提交；
  弹窗打开时由节点数据初始化，不再依赖表单字段。
- 订单管理卡片与订单详情页两处同步修复。

## 二、订单物料自动进入物料库

- **原因**：订单明细一直是「快照」数据，手工录入（未从物料库选择）时不会写入 `material` 表，
  因此物料管理页面为空。
- **修复（两处）**：
  1. **保存订单时自动建档**：明细未关联物料时，按「物料编码（缺省用料号规格）」在物料库中查找；
     不存在则自动创建（名称、规格、品牌、进货价、出货价、含税口径、税率），并回填 `material_id`；
     已存在同编码物料则复用，不重复建档。
  2. **历史数据回填（迁移 v8）**：对已有订单明细中未关联物料的记录，自动建档并回填关联。
- 显式从物料库选择的明细不受影响，物料主数据价格不会被订单价格覆盖。

## 三、数据迁移（V1.6.1 自动执行）

schema_version 7 → 8：历史 `order_item` 回填 `material_code`/`material_name`、自动创建物料并回填 `material_id`。

## 四、验收标准增补

1. 订单管理中点击任意节点（含「需求沟通」），四个状态按钮点选后高亮，保存后状态生效。
2. 新建/编辑订单时手工录入物料并保存后，物料管理中出现对应物料；同编码不重复。
3. 升级后历史订单中的物料自动出现在物料管理，明细与物料建立关联。
4. schema_version 自动升到 8，原有数据保留。
