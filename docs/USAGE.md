# 使用说明（芯片代理商客户订单进度管理系统 V1.3）

## 一、启动

- 打包版：双击安装后的「芯片订单管理」快捷方式；免安装版运行 `ChipAgentERP.exe`（路径必须在 C 盘）。
- 开发版：`pnpm dev`（构建后自动启动）。
- 首次启动自动在 `%APPDATA%\ChipAgentERP\data` 创建数据库与目录，无需任何配置。
- 从旧版本升级：替换程序文件后首次启动会自动升级数据库（V1.3 = schema v4），**原有数据保留**。

## 二、客户管理（卡片式）

1. **客户管理** → 新建客户：只填客户全称即可（全局唯一）；类型、简称、地址、备注、重点客户可选填。
2. 客户以**卡片方块**展示：公司 Logo、客户全称/简称、重点与类型、微信群数、订单数、地址。
3. 卡片右下角按钮：
   - 图片按钮 → 上传/更换公司 Logo（≤5MB，png/jpg 等）；有 Logo 时可删除
   - 「查看」进入客户详情；铅笔按钮编辑；垃圾桶删除（软删除，订单保留）
4. 客户详情页 → 「沟通微信群」：一个客户可加多个群（商务交流群、研发交流群…），
   每个群添加成员：群内微信号/ID（必填）、真实姓名、岗位。

## 三、物料管理（新增一级菜单）

- 新建物料：物料编码（唯一）、物料名称、料号规格、品牌、**进货价**、**出货价**、
  **价格口径（含税/不含税）**、税率（默认 13%）、备注、是否启用。
- 列表可按编码/名称/规格/品牌搜索；显示被引用订单数、最近订单日期；可停用（停用后订单选择器不再出现）。
- 点「关联订单」可查看使用该物料的所有订单，并可直接跳转到订单详情。
- 被订单明细引用的物料不能删除（提示改为停用），保证历史订单可追溯。

## 四、订单管理

1. **订单管理** → 新建订单：
   - 选择客户；订单编号留空自动生成；订单日期/类型/状态等均可留空（显示「未填写」）
   - 「沟通微信群」可从该客户的群中多选
   - **物料明细**：可先从「从物料库选择」带出编码/名称/规格/品牌/进货价/出货价/含税口径/税率，
     也可直接手工录入；填数量、进货价、出货价，选含税/不含税与税率，
     系统自动算「含税单价 / 含税金额」，订单总额 = 各明细含税金额之和
   - 需要折扣/运费/整单议价时勾选「手动设置总金额」，可一键恢复自动汇总
   - 保存后自动生成 10 个标准进度节点
2. **订单文档**：订单详情页「上传 PDF / Word / 图片」（≤50MB），可打开、定位目录、删除。
3. **导出报价单**：订单详情页 →「导出报价单」，生成 Excel：
   - 公司抬头（系统设置 → 报价单 → 公司名称）
   - 表头：物料编码 / 物料名称 / 料号规格 / 品牌 / 需求数量 / 含税单价（元）/ 含税金额（元）/ 备注
   - 明细行（不含税价自动换算为含税单价）→ 合计（含税）→ 备注说明 → 页脚
   - 备注说明与页脚在「系统设置 → 报价单」中可改
4. **跟进进度**：时间线逐节点推进，标记完成会自动填实际时间并进入下一节点；
   全部完成订单自动「已完结」；节点可加跟进记录与附件。

## 五、看板与提醒

- 首页 7 项指标 + 状态分布饼图（含「未填写」扇区）+ 逾期/重点订单列表，数据实时刷新。
- 启动弹窗提示逾期与 3 天内到期节点；右上角铃铛常驻提醒。

## 六、数据工具

- **Excel 导出**：客户列表 / 订单列表 / 订单明细（含物料编码、进货价、出货价、含税口径、含税金额、毛利）。
- **Excel 导入**：客户（仅全称必填）；订单（客户必须已存在，日期/类型/状态可留空）。
- **备份/恢复**：数据库 + 附件（含 Logo、订单文档）+ 报价单设置一并打包为 zip。

## 七、系统设置

- 客户类型 / 订单类型 / 付款方式 / 订单状态（语义）/ 节点模板：可增删改，被引用的不可删。
- **报价单**：公司名称、备注说明（每行一条）、页脚提示语。
- 编号规则：前缀 / 日期格式 / 流水位数，按日重置。
- 存储：查看数据目录、迁移数据目录、设置备份目录。

## 八、注意事项

- 客户删除为软删除：客户从列表消失，其订单保留并计入统计。
- 订单删除会连同明细、节点、订单文档、附件一并删除，不可撤销（可从备份找回）。
- 修改物料主数据不会改动历史订单明细里已保存的价格。
- 数据全部在本地，无网络上传；重装系统前务必先备份并把 zip 拷走。
