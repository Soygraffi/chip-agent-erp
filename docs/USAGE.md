# 使用说明（芯片代理商客户订单进度管理系统 V1.4）

## 一、启动

- 打包版：双击安装后的「芯片订单管理」快捷方式；免安装版运行 `ChipAgentERP.exe`（路径必须在 C 盘）。
- 开发版：`pnpm dev`（构建后自动启动）。
- 首次启动自动在 `%APPDATA%\ChipAgentERP\data` 创建数据库与目录，无需任何配置。
- 从旧版本升级：替换程序文件后首次启动会自动升级数据库（V1.4 = schema v5），**原有数据保留**。

## 二、客户管理（卡片 + 拖动排序）

1. **客户管理** → 新建客户：只填客户全称即可（全局唯一）。
2. 客户以卡片展示，**直接拖动卡片即可调整前后顺序**，松手自动保存。
3. 卡片上可**上传公司 Logo**（图片按钮，≤5MB）；编辑弹窗内也可上传/移除。
4. 卡片显示：Logo、客户全称/简称、重点与类型、微信群数、订单数（跟进中）、地址；操作：查看 / 编辑 / 删除。
5. 客户详情页 → 沟通微信群：可加多个群并维护成员（微信号 → 真实姓名 / 岗位）。

## 三、微信群管理（独立菜单）

- 左侧菜单「微信群管理」：汇总所有客户的群，显示所属客户、备注、成员数。
- 展开某个群可维护成员；右上角「新增微信群」选择客户后建群；可编辑/删除群。

## 四、物料管理

- 物料编码（唯一）、物料名称、料号规格、品牌、**进货价（可选含税/不含税）**、
  **出货价（可选含税/不含税）**、税率（默认 13%）、备注、启用状态。
- **利润率**：填写后自动算出货价（出货价 = 进货价 × (1+利润率%)）。
- 列表显示利润率、被引用订单数、最近订单日期；「关联订单」可反查使用该物料的订单。
- 被订单明细引用的物料不能删除（可改为停用）。

## 五、订单管理

1. **订单列表**不再显示订单编号；点击行首箭头可**直接展开查看该订单的物料明细**，无需进详情。
2. 新建订单：
   - 可留空订单日期/类型/状态（显示「未填写」）；可多选该客户的沟通微信群
   - 物料明细可从物料库带出；**进货价、出货价各自选择含税/不含税**，填利润率自动算售价
   - 系统自动计算含税单价、含税金额与订单总额；支持手动设置总金额并一键恢复自动汇总
   - 保存后自动生成进度节点（顺序以「系统设置 → 节点顺序 / 模板」为准）
3. **订单详情**：
   - 顶部：订单文档（PDF/Word/图片，可打开/删除）、导出订单详情、**导出报价单**
   - 物料明细：含税金额与毛利
   - **进度为横向步骤条**：不显示计划/实际时间与负责人；点击步骤可改名称/状态；
     下方「完成：节点名」按钮推进；无上移/下移（顺序在系统设置维护）

## 六、报价单与系统设置

- **报价单**：订单详情「导出报价单」，公司抬头/备注说明/页脚在「系统设置 → 报价单」维护。
- **排序**：客户类型、订单类型、付款方式、订单状态、节点模板均在系统设置中**拖动排序**（无排序数字）。
- 编号规则、存储设置、备份恢复、Excel 导入导出等与之前一致。

## 七、注意事项

- 客户删除为软删除：客户从列表消失，其订单保留并计入统计。
- 订单删除会连同明细、节点、订单文档、附件一并删除，不可撤销（可从备份找回）。
- 修改物料主数据不会改动历史订单明细中已保存的价格。
- 数据全部在本地，无网络上传；重装系统前务必先备份并把 zip 拷走。
