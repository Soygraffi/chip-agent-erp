# 使用说明（芯片代理商客户订单进度管理系统 V1.0）

## 一、启动

- 打包版：双击安装后的「芯片订单管理」快捷方式；免安装版运行 portable exe。
- 开发版：`pnpm dev`（构建后自动启动）。
- 首次启动自动在 `%APPDATA%\ChipAgentERP\data` 创建数据库与目录，无需任何配置。

## 二、日常操作流程

1. **客户管理** → 新建客户：填写客户全称（全局唯一）、类型、联系人、电话，可标记重点客户（列表高亮）。
2. **订单管理** → 新建订单：
   - 选择客户；订单编号留空自动生成（默认 `XS202610280001`，按日递增，可改前缀/格式/位数）
   - 录入物料明细：芯片型号、品牌、封装、数量、单价；小计与总金额自动计算
   - 需要折扣/运费/整单议价时勾选「手动设置总金额」，可随时一键恢复自动汇总
   - 保存后**自动生成 10 个标准进度节点**（需求沟通 → 报价中 → … → 收款完成）
3. **跟进进度**（订单详情页）：
   - 在时间线中逐节点推进：点「标记完成」自动填实际完成时间并自动进入下一节点
   - 全部节点完成后订单自动变为「已完结」
   - 遇到异常可把节点标为「异常延误」并在跟进记录里写原因
   - 每个节点可追加多条跟进记录、上传多个附件（≤50MB/个，点击直接打开）
4. **看板与提醒**：
   - 首页看板 7 项指标 + 状态分布饼图 + 逾期/重点订单列表，数据变更实时刷新
   - 启动时弹窗提示逾期与 3 天内即将到期的节点；右上角铃铛常驻提醒（角标=逾期数）

## 三、数据工具

- **Excel 导出**：客户列表 / 订单列表 / 订单明细；单订单详情导出为 3 个 sheet（信息/明细/节点）。
- **Excel 导入**：先下载模板 → 填写 → 导入。订单导入要求客户已存在（按全称精确匹配），
  留空编号自动生成、成功行自动生成 10 个节点；导入后展示成功/失败明细（逐行原因）。
- **备份**：一键打包数据库 + 附件为 zip（`backup_日期_时间.zip`，含校验值与版本信息）。
- **恢复**：选择备份 zip → 自动先备份当前数据 → 覆盖 → 重启应用生效。

## 四、系统设置

- **基础字典**：客户类型 / 订单类型 / 付款方式 / 币种 / 节点模板均可增删改；
  被业务数据引用的项禁止删除。
- **订单状态**：可增删改、可自定义颜色；每个状态带「终态/结果(完成·取消)/默认完成」语义，
  统计与自动完结按语义驱动（内置 5 个状态：待确认/进行中/已发货/已完结/已取消）。
- **汇率**：每币种一个手工汇率，下单时快照到订单，修改只影响之后的新单。
- **编号规则**：前缀 / 日期格式 / 流水位数（2–6），按日重置。
- **存储**：查看数据目录；可迁移到新目录（复制数据后切换，旧目录保留回退）；
  设置备份默认目录。

## 五、注意事项

- 客户删除为软删除：客户从列表消失，其订单保留并计入统计（显示「已删除客户」）。
- 订单删除会连同明细、节点、附件一并删除，且不可撤销（可从备份找回）。
- 数据全部在本地，无任何网络上传；重装系统前务必做一次备份并把 zip 拷走。
