# 使用说明（芯片代理商客户订单进度管理系统 V1.2）

## 一、启动

- 打包版：双击安装后的「芯片订单管理」快捷方式；免安装版运行 `ChipAgentERP.exe`（路径必须在 C 盘）。
- 开发版：`pnpm dev`（构建后自动启动）。
- 首次启动自动在 `%APPDATA%\ChipAgentERP\data` 创建数据库与目录，无需任何配置。
- 从旧版本升级：直接替换程序文件即可，首次启动会自动把数据库升级到 V1.2，**原有数据保留**。

## 二、日常操作流程

1. **客户管理** → 新建客户：
   - 只填客户全称即可（全局唯一）；类型、简称、地址、备注、重点客户均可选填
   - 不再有联系人/电话/邮箱/负责业务员/合作起始日期
2. **客户详情页 → 沟通微信群**：
   - 一个客户可以加多个群，例如「商务交流群」「研发交流群」
   - 每个群点「添加成员」录入：群内微信号/ID（必填）、真实姓名、岗位（如采购经理、硬件工程师）
   - 群和成员都可以随时编辑、删除
3. **订单管理** → 新建订单：
   - 选择客户；订单编号留空自动生成（默认 `XS202610280001`，按日递增，可改前缀/格式/位数）
   - 订单日期、类型、状态、交货日期、付款方式、备注都**可以不填**，界面会显示「未填写」
   - 录入物料明细：芯片型号、品牌、封装、数量、单价；小计与总金额自动计算
   - 需要折扣/运费/整单议价时勾选「手动设置总金额」，可随时一键恢复自动汇总
   - 「沟通微信群」可从该客户的群里多选
   - 保存后**自动生成 10 个标准进度节点**（需求沟通 → 报价中 → … → 收款完成）
4. **订单文档（PDF / Word / 图片）**：
   - 订单详情页顶部「订单文档」→「上传 PDF / Word / 图片」
   - 支持 pdf、doc、docx、png、jpg/jpeg、gif、bmp、webp，单文件 ≤ 50MB
   - 列表里可直接「打开」「所在目录」「删除」；删除订单时这些文档一并删除
5. **跟进进度**（订单详情页）：
   - 在时间线中逐节点推进：点「标记完成」自动填实际完成时间并自动进入下一节点
   - 全部节点完成后订单自动变为「已完结」
   - 遇到异常可把节点标为「异常延误」并在跟进记录里写原因
   - 每个节点可追加多条跟进记录、上传多个附件（≤50MB/个，点击直接打开）
   - 节点不再有「负责人」字段
6. **看板与提醒**：
   - 首页看板 7 项指标 + 状态分布饼图（含「未填写」扇区）+ 逾期/重点订单列表，数据变更实时刷新
   - 启动时弹窗提示逾期与 3 天内即将到期的节点；右上角铃铛常驻提醒（角标=逾期数）

## 三、数据工具

- **Excel 导出**：客户列表（含微信群数）/ 订单列表（含沟通微信群列）/ 订单明细；
  单订单详情导出为 4 个 sheet（订单信息 / 物料明细 / 进度节点 / 沟通微信群）。
- **Excel 导入**：先下载模板 → 填写 → 导入。
  - 客户模板只有 5 列：客户全称* / 客户类型 / 客户简称 / 地址 / 备注
  - 订单模板：仅「客户全称」必填，日期/类型/状态可留空；客户必须已存在（按全称精确匹配）
  - 留空编号自动生成、成功行自动生成 10 个节点；导入后展示成功/失败明细（逐行原因）
- **备份**：一键打包数据库 + 附件为 zip（`backup_日期_时间.zip`，含校验值与版本信息）。
- **恢复**：选择备份 zip → 自动先备份当前数据 → 覆盖 → 重启应用生效。

## 四、系统设置

- **基础字典**：客户类型 / 订单类型 / 付款方式 / 节点模板均可增删改；被业务数据引用的项禁止删除。
- **订单状态**：可增删改、可自定义颜色；每个状态带「终态/结果(完成·取消)/默认完成」语义，
  统计与自动完结按语义驱动（内置 5 个状态：待确认/进行中/已发货/已完结/已取消）。
  订单状态留空时按「未填写」展示，统计上视为未结束。
- **编号规则**：前缀 / 日期格式 / 流水位数（2–6），按日重置。
- **存储**：查看数据目录；可迁移到新目录（复制数据后切换，旧目录保留回退）；
  设置备份默认目录。
- 不再有「汇率」设置页；订单金额为单币种（人民币）汇总。

## 五、注意事项

- 客户删除为软删除：客户从列表消失，其订单保留并计入统计（显示「已删除客户」）。
- 订单删除会连同明细、节点、订单文档、附件一并删除，且不可撤销（可从备份找回）。
- 数据全部在本地，无任何网络上传；重装系统前务必做一次备份并把 zip 拷走。
