# PRD V1.6.2 修复说明（相对 V1.6.1）

- 版本：V1.6.2（2026-10-28）
- 问题：把订单状态改成「待确认」并保存后，界面整页变白不可用。

## 一、根因

订单详情页在 V1.6.1 新增了一个用于初始化「更新进度」弹窗的 `useEffect`，但它被写在了
`if (!detail) return <Card loading />;` **之后**。这违反 React Hooks 规则：

- 首次渲染（详情未加载）→ 组件少调用一个 Hook；
- 数据返回后再次渲染 → Hook 数量变化，React 抛错
  （Rendered more hooks than during the previous render）；
- 应用没有错误边界，整棵组件树卸载 → 白屏。

保存订单后会跳转到订单详情页，因此触发该崩溃。**数据本身没有损坏**（已核验数据库：
订单状态、明细、物料关联均正常）。

## 二、修复

1. 将所有 Hook 移到提前 return 之前（订单详情页）。
2. 新增**渲染错误边界**（ErrorBoundary）：任何页面渲染异常时显示错误信息与「重新加载 / 返回首页」按钮，
   不再整页白屏。
3. 增加**错误日志**：渲染层未捕获异常与错误边界信息写入
   `%APPDATA%\ChipAgentERP\logs\renderer.log`，主进程日志写入 `logs\main.log`，便于定位问题。
4. 新增回归守卫测试：静态检查页面组件中“提前 return 之后不得再出现 Hook”，
   防止同类问题再次出现。

## 三、验收标准

1. 修改订单状态（如待确认）并保存后，正常进入订单详情页，不再白屏。
2. 任意页面若发生渲染异常，显示错误提示页而不是白屏。
3. 发生异常时可在 logs 目录找到对应日志。
4. 测试全绿（216 个，新增 Hook 顺序守卫）。
