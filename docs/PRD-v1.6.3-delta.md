# PRD V1.6.3 修复说明（相对 V1.6.2）

- 版本：V1.6.3（2026-10-28）
- 问题：订单管理中每个订单进度条的第一个步骤「需求沟通」无法点击，无法设置当前进度状态。

## 一、根因

进度条使用 antd `Steps` 组件，其点击回调实现为：

```js
if (onChange && current !== next) { onChange(next); }
```

即：**点击“当前所在步骤”时不会触发 onChange**。订单的当前步骤正是第一个未完成节点
（通常是「需求沟通」），因此点击它永远没有反应；其它步骤可点。

补充：此前 V1.6.1/V1.6.2 的 Hook 与表单问题已修复，本次是组件点击语义问题。

## 二、修复

- 用自研组件 **NodeStepper** 替代 antd Steps：
  - 横向步骤条，每一步的整块区域（圆点 + 名称 + 状态）都可点击；
  - 点击任意步骤（含第一步）都会打开「更新进度」弹窗；
  - 圆点颜色随节点状态变化（未开始灰、进行中蓝、已完成绿、异常红），已完成显示 ✓；
  - 支持鼠标悬停高亮，视觉与之前一致。
- 订单管理卡片与订单详情页统一使用该组件。
- 新增回归测试：禁止在进度条处使用 antd Steps，并要求使用 NodeStepper。

## 三、验收标准

1. 订单管理中点击任意订单的第一个步骤「需求沟通」，能打开更新进度弹窗。
2. 四个状态按钮点选后高亮，确定后步骤颜色/文案变化，卡片顶部状态同步。
3. 订单详情页进度条同样可点。
4. 测试全绿（219 个，新增进度条实现守卫）。
