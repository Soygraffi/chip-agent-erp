# PRD V1.10.2 变更说明（相对 V1.10.1）

- 版本：V1.10.2（2026-11-01）
- 依据：用户指出进度不应只是表格里的一栏，而是**每颗料各有一条进度线**。

## 变更

- 订单详情页移除物料明细表里的「时间轴进度」列。
- 新增「**物料进度**」区域：每颗物料一张卡片，卡片内是一条完整步骤条（与订单级进度同样的样式）：
  1. 需求沟通
  2. 报价中
  3. 客户确认
  4. 下单
  5. 供应商备货
  6. 到货
  7. 出货
  8. 客户签收
  9. 收款完成
- 卡片标题显示：品牌 + 物料名称 + 料号规格；右上角显示「第 N 步 · 阶段名」。
- 已完成阶段显示为完成态、当前阶段进行中、后续未开始（颜色与订单进度节点一致）。
- **点击任意步骤**即可把该物料调整到该阶段（弹窗确认后保存），每颗料互不影响。
- 订单整体「按进度排序」仍按各物料阶段平均值计算，最快在前。
- 订单级进度节点（原有「进度」区域）保留不变。

## 测试

- 更新 UI 断言：详情页存在「物料进度（每颗料一条时间轴）」、按物料生成步骤条，且表格不再有「时间轴进度」列。
- 共 **267** 个测试全部通过。

## 验收标准

1. 打开订单详情，每颗物料都有自己的进度线（需求沟通→…→收款完成）。
2. 点某颗料进度线上的某一步，只改这颗料的阶段，其它料不受影响。
3. 物料明细表格里不再有「时间轴进度」列。
