# PRD V1.5 变更说明（相对 V1.4）

- 版本：V1.5（2026-10-28）
- 依据：用户 4 项反馈（进度可编辑并去掉方块按钮、订单管理直接看/管进度与物料字段、微信群编辑可改客户并加成员表格、首页看板调整）

## 一、进度可自行编辑（订单详情）

- 横向步骤条中，**点击任意步骤**即可编辑该节点的名称与「当前进度状态」
  （未开始 / 进行中 / 已完成 / 异常延误），即“目前进度到哪了”。
- **删除**步骤条下方一排“完成：节点名”方块按钮，统一改为点选步骤编辑。
- 步骤条下方增加提示文案说明该操作。

## 二、订单管理：直接看到并管理进度 + 物料字段

- 订单管理不再使用折叠展开/二级页面，改为**订单卡片列表**，每条订单直接展示：
  - 客户名称、联系人、订单状态、类型、金额、订单日期、预计交期、逾期/重点标记
  - **横向进度步骤条**：点击步骤即弹出“更新进度”，可修改节点名称与状态
  - **物料明细表**：物料名称、料号规格、品牌、数量、含税金额
- 顶部筛选：客户/编号/型号搜索、状态、类型、日期范围、仅看逾期、排序（日期/金额/交期升降）、刷新。
- 仍保留「编辑 / 删除 / 进入详情」操作；详情页功能不变。

## 三、微信群管理

- **编辑群时可修改所属客户**（下拉不再禁用）；群转移到新客户后，
  不属于新客户的订单群关联会自动清理，避免串单。
- 编辑群弹窗内提供**群成员表格**：可直接在表格里输入/修改
  「微信号 / 真实姓名 / 任职公司 / 岗位」，失焦自动保存；支持“添加成员行”与删除。
- 表格上方提供搜索框，可按**微信名 / 姓名 / 公司**过滤（输入即查询）。
- 群成员新增「任职公司」字段（数据库同步增加 `company`）。

## 四、首页看板调整

- **删除**「逾期订单数」指标卡与「逾期订单（按逾期天数倒序）」列表。
- 原「重点跟进订单」列表改为 **「订单管理」**，内容与订单管理页一致（同一组件）：
  客户/联系人/状态/类型/金额/日期/交期 + 横向进度 + 物料明细，可直接点步骤更新进度。
- 保留指标：客户总数、跟进中订单数、本月新增订单数、本月订单总金额、待发货订单数、重点跟进订单数；
  保留订单状态分布饼图。

## 五、数据迁移（V1.5 自动执行）

schema_version 5 → 6：

- `customer` 增加 `contact`（联系人，可选，用于订单列表展示）；
- `wechat_member` 增加 `company`（任职公司）。

## 六、验收标准增补

1. 订单详情点击进度步骤可修改节点名称与状态；不再有“完成：xxx”方块按钮。
2. 订单管理页每条订单直接显示进度步骤与物料明细（名称/规格/品牌/数量），可直接更新进度。
3. 编辑微信群可改所属客户；成员表格可输入并保存微信号、姓名、公司、岗位，且可按微信名搜索。
4. 首页无逾期指标与逾期列表；「订单管理」区与订单管理页展示一致。
5. 升级后原有数据完整保留，schema_version 自动升到 6。
