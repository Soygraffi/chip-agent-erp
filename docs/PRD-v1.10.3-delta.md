# PRD V1.10.3 变更说明（相对 V1.10.2）

- 版本：V1.10.3（2026-11-01）
- 依据：用户反馈总进度与物料进度容易混淆，要求总进度在上、物料进度在下并区分视觉。

## 布局调整

订单详情页从上到下：

1. 订单基本信息
2. **订单总进度**（浅蓝底卡片，整张订单共用）
3. 备注
4. 采购合同
5. 物料明细
6. **各物料进度**（每颗料一条，灰色卡片 + 左侧色条）
7. 订单文档（最后）

## 视觉区分

- **订单总进度**：浅蓝背景、蓝色边框；标题带「x/y 已完成」进度标签；右上角「新增节点」；下方说明「整张订单共用的总进度」。
- **各物料进度**：白色卡片包住所有物料；每颗料是浅灰小卡片，左侧 4px 色条（进行中蓝色、到最后一步绿色），标题行显示品牌/物料名称/型号，右侧显示「第 N 步 · 阶段名」。
- 两块区域标题不同（「订单总进度」vs「各物料进度」），并各自带说明文字，避免混淆。

## 测试

- 更新 UI 断言：总进度出现位置在物料进度之前、两块区域标题存在。
- 共 **267** 个测试全部通过。

## 验收标准

1. 订单详情顶部能看到「订单总进度」，下方物料明细之后才是「各物料进度」。
2. 两块区域视觉明显不同，不会混淆。
3. 点击行为不变：总进度点步骤编辑节点，物料进度点步骤调整该颗料阶段。
