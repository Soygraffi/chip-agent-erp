# PRD V1.9.1 变更说明（相对 V1.9）

- 版本：V1.9.1（2026-10-30）
- 依据：用户反馈 5 条（供应商详情、下拉简称、物料明细简化、报价单按钮去重、重点跟进样式）。

## 1. 供应商详情能看到订单独的供应商与物料

- 供应商详情里的「涉及的订单」「供货物料」改为**同时匹配两种关联**：
  - 订单明细行里直接指定的供应商（V1.9 新增的 `order_item.supplier_id`）；
  - 物料库里的供应商（兼容老数据）。
- 订单聚合的条目数/金额也只统计该供应商实际供应的明细行。
- 物料列表包含“仅在订单明细里指定给该供应商、但物料库未关联”的物料。

## 2. 客户/供应商下拉显示简称

- 订单录入的客户下拉、明细行的供应商下拉：**有简称就显示简称**，没有简称才显示全称。
- 下拉选项接口（customers.options / suppliers.options）补充返回 `shortName`。

## 3. 物料明细简化

- 去掉「从物料库选择」列（录入仍会自动在后台关联/建立物料库记录）。
- 「物料名称」列宽 130 → **200**，「料号规格」列宽 140 → **220**，长名称/型号可完整显示；表格横向滚动宽度同步加大。

## 4. 去掉重复的报价单按钮

- 订单详情页删除原 Excel「导出报价单」，只保留「导出报价单（Word）」。
- 首页看板不显示报价单按钮（沿用 V1.8.2）。

## 5. 重点跟进改为开关

- 订单表单的「重点跟进」由复选框改为 **Switch**（重点 / 普通），带文字状态并做垂直对齐，视觉更整齐。

## 测试

- 新增：订单明细指定供应商后供应商详情的订单/物料可见、下拉简称、物料列移除与加宽、详情页仅 Word 按钮、Switch 样式。
- 共 **254** 个测试全部通过。

## 验收标准

1. 给订单明细选供应商后，供应商详情能看到该订单与该物料。
2. 客户/供应商下拉显示简称（有简称时）。
3. 新建订单物料明细不再有「从物料库选择」，名称与规格列变宽。
4. 订单详情只有「导出报价单（Word）」。
5. 重点跟进为开关且与同排字段对齐。
