# PRD V1.10.4 变更说明（相对 V1.10.3）

- 版本：V1.10.4（2026-11-03）
- 依据：两条需求——节点增加「无」状态；删除独立的「订单状态」，首页饼图改按节点统计。

## 1. 节点状态增加「无（客户未继续）」

- 节点编辑弹窗的状态选项新增：**无（客户未继续）**。
- 含义：需求沟通或报价后客户没有继续下单，订单到此为止。
- 订单卡片与详情页的订单结果标签显示「无 · 客户未继续下单」。
- 数据库迁移（schema 13 → 14）重建 `order_node` 表，允许 `status = 'none'`；同步重建 `node_follow_up`、`node_attachment`，数据完整保留（已用现有库验证：79 个节点前后一致，无外键异常）。

## 2. 删除「订单状态」，改用节点

- 新建/编辑订单表单：移除「订单状态」字段。
- 订单管理筛选：移除「订单状态」下拉。
- 系统设置：移除「订单状态（语义）」标签页。
- 订单状态改由**进度节点**推导：
  - 全部节点完成 → 已完结
  - 任一节点为「无」→ 无 · 客户未继续下单
  - 否则显示当前进行到的节点（如「客户确认 · 进行中」）
- 首页看板饼图改为「**订单进度分布（按当前节点）**」：
  - 每张订单统计其当前进行到的节点；
  - 没有节点的订单计入「未填写」；
  - 全部完成的计入「已完结」；
  - 节点为「无」的计入「无（客户未继续下单）」。
- 饼图悬浮说明与图例文案同步更新。

## 测试

- 新增：节点可设为 none、表单/筛选/设置不再出现订单状态、饼图按节点统计、节点状态文案。
- 更新：stats 与验收测试的分布口径（按当前节点）。
- 共 **275** 个测试全部通过；迁移在现有数据库副本验证通过（13 → 14）。

## 验收标准

1. 编辑任意订单节点，状态里能选「无（客户未继续）」，保存后订单显示「无 · 客户未继续下单」。
2. 新建订单不再有「订单状态」字段；订单管理没有状态筛选；系统设置没有状态语义页。
3. 首页饼图标题为「订单进度分布（按当前节点）」，扇区是各节点名/已完结/未填写/无。
