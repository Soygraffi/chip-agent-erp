# PRD V1.8.1 变更说明（相对 V1.8）

- 版本：V1.8.1（2026-10-29）
- 依据：订单管理里已有订单也要能像新建订单一样，先弹窗填写再导出报价单。

## 变更

### 1. 报价单弹窗抽成通用组件

新增 `QuoteModal` 组件，统一承接：客户单位全称、对接人、联系电话（客户）、客户地址、
报价日期、报价有效期、报价人、报价人电话、备注说明（逐行可编辑/增删）。

所有字段非必填；留空栏目在 Word 中自动隐藏；备注可点「添加一条备注」追加。

### 2. 三个入口共用同一弹窗

| 入口 | 位置 | 说明 |
|---|---|---|
| 新建/编辑订单 | 表单底部「导出报价单（Word）」 | 用当前填写的明细与总金额 |
| **订单管理卡片** | 每张卡片右上角「报价单」 | 用该订单已保存的明细、金额、客户 |
| **订单详情页** | 标题栏「导出报价单（Word）」 | 同上；原 Excel「导出报价单」保留 |

订单管理卡片新增按钮不改变原有编辑/删除/进度操作。

### 3. 数据来源

- 客户单位全称、对接人、客户地址：默认取客户资料，可改。
- 报价人、报价人电话、备注条款：默认取「系统设置 → 报价单」。
- 明细与金额：来自当前订单（新建页为表单当前值）。

## 测试

- 新增 `tests/ui/quote-entries.test.ts`：三个入口均复用 QuoteModal、字段齐全、空值提示存在。
- 更新表单布局测试以匹配组件化后的实现。
- 共 **238** 个测试全部通过。

## 验收标准

1. 订单管理卡片上点「报价单」会弹出填写窗口，确认后导出 .docx。
2. 订单详情页「导出报价单（Word）」同样弹出填写窗口。
3. 三个入口的弹窗字段、空值隐藏、备注增删行为一致。
4. 导出内容与该订单明细/金额一致。
