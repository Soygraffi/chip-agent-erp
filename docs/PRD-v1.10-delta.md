# PRD V1.10 变更说明（相对 V1.9.2）

- 版本：V1.10（2026-11-01）
- 本轮 6 条需求（Logo、删除客户、明细交货日期、进度条、按进度排序、默认展示顺序）。

## 1. 去掉 Logo 的「移除」按钮

- 客户卡片与编辑弹窗只保留「上传/更换 Logo」，不再提供「移除 Logo」。

## 2. 删除客户移到系统设置

- 客户管理页、客户卡片不再有删除按钮。
- 系统设置新增「**删除客户**」标签页（危险操作）：
  - 选择客户 → 手动输入「确认删除」→ 删除按钮才可用；
  - 弹窗二次确认；
  - 删除后客户从列表移除，历史订单保留。

## 3. 物料明细的实际交货日期

- 订单物料明细每行新增「**实际交货日期**」列（DatePicker），每个料可以不同。
- 数据库：`order_item.actual_delivery_date`。
- 订单详情物料表显示每行实际交货日期。

## 4. 订单详情自定义进度条

- 物料明细新增「**进度**」列：显示进度条 + 自定义名称。
- 点「设置/名称」打开弹窗，可为该物料：
  - 命名进度（如「已下单」「已到货」「已出货」）；
  - 设置完成百分比 0–100%。
- 数据库：`order_item.progress`、`order_item.progress_label`。
- 进度按物料单独保存，互不影响；订单整体进度 = 各物料进度平均值。
- 原有「进度节点」仍支持新增/命名/排序（订单级流程）。

## 5. 订单管理按进度排序

- 订单管理排序下拉新增「**按进度 ↓（最快在前）**」「按进度 ↑（最慢在前）」。
- 排序在后端完成（按明细进度平均值），分页正确。
- 订单卡片标题显示「进度 xx%」，便于直观比较。

## 6. 系统设置里配置订单展示顺序

- 系统设置新增「**订单展示顺序**」标签页，可选：
  订单日期 ↓/↑、进度 ↓/↑、金额 ↓/↑、交期 ↑/↓。
- 保存后，进入订单管理时按该顺序展示；页面里仍可临时切换。

## 迁移与兼容

- schema 11 → 12：新增 `order_item.actual_delivery_date / progress / progress_label`。
- 老数据：进度默认 0、名称为空、实际交货日期为空；已在数据库副本验证迁移成功。

## 测试

- 新增：明细交货日期与进度读写、进度越界收敛、按进度排序、迁移字段、设置默认排序、删除客户入口、UI 结构等。
- 共 **266** 个测试全部通过。

## 验收标准

1. 客户页无删除按钮；系统设置里能安全删除客户。
2. 订单明细每行可填不同的实际交货日期。
3. 每行物料可命名并设置进度条，保存后显示。
4. 订单管理可按进度排序，最快的在最前，卡片显示进度%。
5. 系统设置可设置默认展示顺序，进入订单管理生效。
