# PRD V1.8.2 变更说明（相对 V1.8.1）

- 版本：V1.8.2（2026-10-29）
- 依据：首页看板里的订单列表不需要「报价单」按钮。

## 变更

- `OrdersBoard` 新增 `showQuote` 属性（默认 `true`）。
- **首页看板**：`<OrdersBoard showFilters={false} pageSize={5} showQuote={false} />`，不显示「报价单」。
- **订单管理页**：保持默认 `true`，卡片右上角仍有「报价单」按钮。
- 订单详情页的「导出报价单（Word）」不受影响。

## 测试

- 新增断言：首页看板传入 `showQuote={false}`，订单管理页不传该属性。
- 共 **239** 个测试全部通过。

## 验收标准

1. 首页看板的订单卡片不再出现「报价单」按钮。
2. 订单管理页的订单卡片仍可点「报价单」弹窗导出。
