# PRD V1.7 变更说明（相对 V1.6.6）

> 说明：本版本前源码目录曾被清理，已从 GitHub 重新克隆至 `C:\Users\pengh\Projects\chip-agent-erp` 后继续开发。

## 一、供应商详情页

- 供应商卡片可点击进入详情（`/suppliers/:id`），与客户管理一致。
- 详情页展示：
  - 基本信息（全称/简称/联系人/电话/地址/备注）
  - 统计卡：涉及订单数、供货物料种数、累计含税金额
  - **涉及的订单**：订单编号（可跳转订单详情）、客户、订单日期、订单状态、供货物料条目数、本次供货含税金额
  - **供货物料**：编码、名称、规格、品牌、进货价、出货价、关联订单数、状态

## 二、订单管理显示微信群名称

- 订单管理卡片标题行新增**沟通微信群名称标签**（青色，带微信图标），直接可见该订单关联的所有群。
- 订单总览接口（orders:overview）同步返回 `wechatGroups`。

## 三、新建订单列顺序调整

- 物料明细列顺序：… 出货价 → 出货口径 → **税率** → **利润率** → 含税单价 → 含税金额 …
- 即「利润率」移到「税率」之后。

## 四、新建订单导出 Word 报价单

- 新建/编辑订单页底部新增按钮「**导出报价单（Word）**」。
- 无需先保存订单：直接用当前已填写的客户、订单编号、物料明细与总金额生成 `.docx`。
- 版式：公司抬头（系统设置 → 报价单）、标题「报 价 单」、客户/订单号/报价日期、
  8 列明细表（物料编码/物料名称/料号规格/品牌/需求数量/含税单价/含税金额/备注）、
  合计（含税）、备注说明（每行一条）、页脚。
- 不含税价自动按税率换算为含税单价；金额保留两位小数并千分位。
- 文件默认名：`报价单_{客户名}_{yyyyMMdd_HHmm}.docx`。
- 实现方式：自研 OOXML 生成（adm-zip 打包），不引入额外依赖。
