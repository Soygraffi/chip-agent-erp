# PRD V1.6.5 变更说明（相对 V1.6.4）

- 版本：V1.6.5（2026-10-28）
- 依据：用户反馈（节点名称调整；明确订单状态含义）

## 一、节点模板改名

- 内置节点模板「供应商备货/排产」更名为「供应商备货」（语义码仍为 `stock`，不影响待发货统计口径）。
- 已有订单中该节点的名称同步更名（迁移 v9，仅匹配以「供应商备货」开头的节点名）。
- 新建订单自动生成的节点名称即为「供应商备货」。

## 二、订单状态含义说明

明确内置状态的业务含义：

| 状态 | 含义 |
|---|---|
| 待确认 | 客户还未下单完成（询价 / 规格确认中） |
| 进行中 | 客户下单完成后的执行状态 |
| 已发货 | 已发货，等待签收 / 对账 |
| 已完结 | 订单全部完成 |
| 已取消 | 订单已取消 |
| 未填写 | 尚未设置订单状态 |

展示位置：

1. **首页看板 → 订单状态分布**：饼图下方新增「状态说明」图例（颜色点 + 状态名 + 含义）；
   鼠标悬浮扇区时，提示框同时显示该状态的含义。
2. **系统设置 → 订单状态（语义）**：顶部新增状态含义约定提示条。

## 三、数据迁移（V1.6.5 自动执行）

schema_version 8 → 9：`node_template` 与 `order_node` 中「供应商备货/排产」批量更名为「供应商备货」。

## 四、验收标准

1. 系统设置 → 节点顺序 / 模板 中显示「供应商备货」；新建订单的对应节点名称一致。
2. 已有订单详情中的该节点名称已更新。
3. 首页订单状态分布下方可看到各状态含义；悬浮饼图扇区提示含含义。
4. 系统设置订单状态页顶部有含义说明。
5. 测试全绿（220 个）。
