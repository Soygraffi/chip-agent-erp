# PRD V1.3 变更说明（相对 V1.2）

- 版本：V1.3（2026-10-28）
- 依据：用户提供「报价单」Excel 样板截图 + 反馈（价格要分进货价/出货价、含税/不含税可选、一键导出报价单；客户管理改卡片式、可上传 Logo；新增物料管理一级菜单）
- 关联：PRD-v1.2-delta.md、data-model.md（已同步）

## 一、物料字段（订单明细）

明细行字段对齐报价单，并新增价格口径：

| 字段 | 必填 | 说明 |
|---|---|---|
| 物料编码 | 否 | 可从物料库带出 |
| 物料名称 | 否 | |
| 料号规格 | 是 | 如 GD32F407ZGT6（原「芯片型号」） |
| 品牌 | 否 | |
| 需求数量 | 是 | 非负整数 |
| 进货价 | 否 | 成本价，用于毛利 |
| 出货价 | 否 | 报价/成交价 |
| 价格口径 | 是 | **含税 / 不含税**（默认含税） |
| 税率(%) | 是 | 默认 13，可改 |
| 含税单价 | 自动 | 含税价直接用；不含税价 = 出货价 ×(1+税率) |
| 含税金额 | 自动 | 数量 × 含税单价（2 位小数），订单总额 = Σ含税金额 |
| 毛利 | 自动 | 数量 ×（含税出货价 − 含税进货价），仅展示不入库 |

## 二、物料管理（新增一级菜单）

- 物料主数据：物料编码（唯一，归一化判重）、物料名称、料号规格、品牌、进货价、出货价、
  价格口径（含税/不含税）、税率、备注、启用状态。
- 列表支持按编码/名称/规格/品牌搜索、启用状态筛选；显示被引用订单数与最近订单日期。
- 与订单联动：
  - 订单明细可从物料库选择，自动带出编码/名称/规格/品牌/进货价/出货价/含税口径/税率；
  - 物料管理页「关联订单」抽屉列出使用该物料的所有订单（可跳转订单详情）；
  - 被订单明细引用的物料禁止删除（提示可改为停用）；停用后不再出现在订单选择器。
- 修改物料主数据不影响历史订单明细中的价格快照（明细保存独立字段）。

## 三、一键导出报价单（新增）

订单详情页「导出报价单」按钮，输出 Excel（版式对齐用户提供的报价单样板）：

1. 第 1 行：公司名称（系统设置 → 报价单 → 公司名称，大号加粗居中）
2. 第 2 行：标题「报价单」
3. 表头：物料编码 / 物料名称 / 料号规格 / 品牌 / 需求数量 / 含税单价（元）/ 含税金额（元）/ 备注
4. 明细行（一行一条明细；不含税价格自动换算为含税单价）
5. 合计（含税）= 订单总金额
6. 备注说明（每行一条，系统设置可改；默认交货周期 + 付款方式）
7. 页脚提示语 + 小字客户/订单号/报价日期
8. 文件名：`报价单_{订单编号}_{yyyyMMdd_HHmm}.xlsx`

## 四、客户管理界面（卡片化）

- 由表格改为卡片（方块）网格布局，每行 4/3/2/1 个（随窗口自适应）。
- 卡片内容（详略得当）：
  - 公司 Logo（可上传/更换/移除，正方形，缺省显示客户名前两字）
  - 客户全称（超长省略 + tooltip）、简称
  - 重点标签 + 客户类型
  - 微信群数、订单数（含跟进中）、地址
  - 操作：查看 / 编辑 / 上传 Logo / 移除 Logo / 删除
- Logo 存放于 `attachments/customer-logos/{customerId}/`，随数据目录一起备份迁移；≤5MB，仅图片格式。
- 搜索、类型/重点筛选保留；分页 12/24/48。

## 五、数据迁移（V1.3 自动执行）

schema_version 3 → 4，启动时自动迁移，保留数据：

- 新增 `material` 表（物料主数据）；
- `order_item` 增加 material_id / material_code / material_name / purchase_price / price_tax_included / tax_rate；
- `customer` 增加 logo_path；
- 新增设置项：company_name（报价单抬头）、quote_terms（备注说明）、quote_footer（页脚）。

## 六、验收标准增补

1. 明细可填物料编码/名称/规格/品牌/数量/进货价/出货价，并选择含税或不含税、税率；含税金额与订单总额自动计算。
2. 物料管理可增删改查；订单明细可从物料库选择并自动带出；物料页可反查关联订单；被引用物料不可删除。
3. 订单详情可一键导出报价单，版式包含公司抬头、明细、合计（含税）、备注说明；不含税价自动换算。
4. 客户管理为卡片布局，可上传 Logo 并显示；Logo 随备份/数据目录迁移。
5. 升级后原有客户/订单/节点/微信群数据完整保留，schema_version 自动升到 4。
