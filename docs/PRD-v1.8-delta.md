# PRD V1.8 变更说明（相对 V1.7.2）

- 版本：V1.8（2026-10-29）
- 依据：用户要求导出报价单前先弹窗填写信息；空字段不显示；备注说明可增删编辑。

## 一、导出前填写弹窗

新建/编辑订单页点击「导出报价单（Word）」后，先弹出「导出报价单（Word）」窗口，字段：

| 字段 | 默认值 | 留空效果 |
|---|---|---|
| 客户单位全称 | 当前订单客户名称 | 不显示客户行 |
| 对接人 | 客户资料中的联系人 | 不显示对接人 |
| 联系电话（客户） | 空 | 不显示电话 |
| 客户地址 | 客户资料中的地址 | 不显示地址行 |
| 报价日期 | 今天 | 不显示报价日期 |
| 报价有效期（天） | 30 | 不显示有效期（0 也视为空） |
| 报价人 | 系统设置→报价单→报价人 | 不显示报价人 |
| 报价人电话 | 系统设置→报价单→联系电话 | 不显示电话 |
| 备注说明 | 系统设置→报价单的条款（默认两条） | 全部删空则不显示备注块 |

- 所有字段**均非必填**；留空的栏目不会出现在 Word 中（对应标签也不会残留）。
- 行内字段按实际有值的数量均分制表位，保证对齐；客户地址单独一行，避免换行错位。

## 二、备注说明可增删编辑

- 弹窗中备注说明为逐行输入框，初始为系统设置中的条款（默认 2 条）。
- 每条可编辑；右侧删除按钮可移除该条；底部「**添加一条备注**」在末尾追加一行。
- 导出时只输出非空行；若全部为空，则整块不显示。

## 三、版式与导出

- 仍为 A4 横版、8 列明细、合计（含税总金额）+ 人民币大写、签章区（盖章处仅在填写报价人/电话时出现）。
- 明细与合计始终输出；表头跨页重复。
- 文件名：`报价单_{客户名}_{yyyyMMdd_HHmm}.docx`。

## 四、测试

新增/更新：字段完整、全空字段隐藏、部分为空、备注增删、金额换算、大写转换等用例。
共 **234** 个测试全部通过；示例文档经 LibreOffice 渲染检查版式正常。

## 五、验收标准

1. 点导出先出现填写弹窗，字段均可修改。
2. 留空的字段在 Word 中对应栏目消失，其余栏目对齐正常。
3. 备注可编辑、可删、可通过加号追加，导出内容与弹窗一致。
4. 生成的 Word 为 A4 横版且不超出可打印区域。
