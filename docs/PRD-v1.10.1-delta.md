# PRD V1.10.1 变更说明（相对 V1.10）

- 版本：V1.10.1（2026-11-01）
- 依据：用户对 V1.10 的 4 条修正（占位文字、进度百分比、每颗料时间轴、拖动设置订单顺序）。

## 1. 去掉「每颗料可不同」占位

- 物料明细「实际交货日期」列不再显示灰色提示文字，只保留日期选择器。

## 2. 进度改为时间轴阶段，不再有百分比

- 删除「完成百分比 / 进度名称」那套手填百分比。
- 每颗物料改用固定时间轴（9 步）：
  1. 需求沟通
  2. 报价中
  3. 客户确认
  4. 下单
  5. 供应商备货
  6. 到货
  7. 出货
  8. 客户签收
  9. 收款完成
- 订单详情物料表「时间轴进度」列显示「当前阶段（第 N 步）」，点「调整」选择进行到哪一步。
- 数据库仍用 `order_item.progress` 字段，但存的是阶段序号（0–8）；迁移时把历史的百分比值清零。

## 3. 订单按进度排序 = 按时间轴阶段排序

- 「按进度 ↓（最快在前）」按各物料阶段的平均值排序（阶段越高越靠前）。
- 订单卡片不再显示百分比，改为显示「阶段 xxx」。

## 4. 系统设置改为拖动订单排序

- 「订单展示顺序」标签页改为：直接拖动订单列表调整先后顺序 → 保存。
- 数据库：`orders.sort_order`（迁移时按 id 初始化）。
- 订单管理排序下拉新增「**按设置排序（自定义）**」，按拖动后的顺序展示。
- 原有按日期/金额/交期/进度排序保留。

## 迁移与兼容

- schema 12 → 13：`orders.sort_order`；历史明细百分比归零（转为时间轴第 1 步）。
- 已在现有数据库副本验证迁移成功。

## 测试

- 更新/新增：明细阶段读写、按阶段排序、手动排序顺序、迁移字段、设置拖动保存、UI 结构等。
- 共 **267** 个测试全部通过。

## 验收标准

1. 实际交货日期列没有灰色占位文字。
2. 物料明细的进度是「需求沟通/报价中/客户确认…」的时间轴，可逐条调整，无百分比。
3. 订单管理「按进度」时按时间轴阶段排序，最快的在前。
4. 系统设置里可拖动订单保存顺序，订单管理可选「按设置排序」查看。
