# PRD V1.9.2 变更说明（相对 V1.9.1）

- 版本：V1.9.2（2026-10-30）
- 依据：订单详情页布局调整（订单文档下移、新增可编辑备注栏）。

## 1. 订单文档移到最后

- 订单详情页的「订单文档」卡片从顶部移到**页面最后**（进度节点之后），不再挡在物料明细和采购合同前面。
- 上传/打开/所在目录/删除功能不变。

## 2. 采购合同上方新增「备注」栏

- 在「采购合同」上方新增一张与采购合同**同样式**的卡片：「备注」。
- 卡片内是多行文本框，可直接打字（3~8 行自适应）。
- 右上角「保存备注」把内容写入订单的 `remark` 字段，保存后提示并刷新。
- 原详情页顶部「备注」只读行已去掉，避免重复。

## 页面顺序（从上到下）

1. 订单基本信息
2. **备注**（可编辑）
3. **采购合同**（图片）
4. 物料明细
5. 进度节点
6. **订单文档**（最后）

## 测试

- 新增：订单文档位于进度之后、备注在采购合同上方、备注可编辑并调用 orders.update 保存。
- 共 **257** 个测试全部通过。

## 验收标准

1. 订单详情页最下面是「订单文档」。
2. 「采购合同」上面是「备注」，可直接输入并保存，刷新后仍在。
