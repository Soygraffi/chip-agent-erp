# PRD V1.4 变更说明（相对 V1.3）

- 版本：V1.4（2026-10-28）
- 依据：用户 9 项反馈（微信群独立菜单、客户卡片拖动排序、Logo、利润率算出货价、价格含税/不含税分别可选、订单列表不显示编号、进度横排精简、订单列表内联明细、设置排序改拖动）
- 关联：PRD-v1.2-delta.md / PRD-v1.3-delta.md、data-model.md（已同步）

## 一、微信群管理（独立一级菜单）

- 左侧菜单新增 **微信群管理**（与客户管理平级，位于其后）。
- 页面汇总所有未删除客户的微信群：群名称、所属客户、备注、成员数；展开行查看/维护成员
  （微信号 → 真实姓名 / 岗位），支持新增群（选择客户）、编辑群、删除群、增删改成员。
- 客户详情页内的微信群管理保留。

## 二、客户卡片拖动排序

- 客户管理页面取消分页，全部客户按 `sort_order` 展示为卡片网格。
- 直接拖动卡片到目标位置即可调整前后顺序，松手自动保存（`customers:reorder`）。
- 列表排序始终以拖动后的顺序为准（新客户追加到末尾）。

## 三、客户 Logo 上传

- 卡片上的图片按钮可上传/更换 Logo；有 Logo 时提供删除按钮。
- 编辑客户弹窗内也提供 Logo 预览 + 上传/移除（V1.3 已有卡片入口，V1.4 补齐编辑入口）。
- Logo 存放 `attachments/customer-logos/{customerId}/`，≤5MB，随备份迁移。

## 四、利润率自动算出货价

- 物料库与订单明细均增加「利润率（%）」输入：填写后 **出货价 = 进货价 × (1 + 利润率/100)**（保留 4 位小数）。
- 已填进货价与出货价时自动显示当前利润率；改动价格会清空该行的利润率手填值。
- 进货价为 0/空时利润率不可填（提示先填进货价）。

## 五、价格含税/不含税分别可选

- **进货价**与**出货价**各自有「含税 / 不含税」选择（物料库、订单明细均可选），不再共用一个口径。
- 金额计算：
  - 含税出货单价 = 出货价（含税）或 出货价 × (1+税率/100)（不含税）
  - 含税金额 = 数量 × 含税出货单价
  - 毛利 = 数量 ×（含税出货单价 − 含税进货单价），两者按各自口径换算
- 税率仍按行维护（默认 13%）。

## 六、订单管理不显示订单编号

- 订单列表不再显示「订单编号」列；编号仍在内部生成/导出/搜索中使用。
- 通过「操作 → 详情」进入订单详情页（页面标题显示编号）。

## 七、进度时间线横向化与精简

- 进度由竖向时间线改为**横向步骤条（Steps）**，节点从左到右依次排列。
- 删除每个节点的「计划完成时间」「实际完成时间」「负责人」展示与编辑。
- 删除节点的「跟进记录」与「附件」入口（历史数据保留在库中，不再展示）。
- 删除「上移/下移」按钮；**节点顺序统一在「系统设置 → 节点顺序 / 模板」拖动维护**，
  影响之后新建订单的节点顺序，历史订单不受影响。
- 点击步骤可编辑节点名称与状态；下方保留「完成：节点名」快捷按钮；可新增/删除节点。

## 八、订单列表内联物料明细

- 订单管理表格支持**展开行**：点击行首展开箭头即可直接看到该订单的物料明细
  （物料编码、名称、料号规格、品牌、数量、进货价、出货价、含税金额），无需进入详情页。

## 九、系统设置排序改为拖动

- 客户类型 / 订单类型 / 付款方式 / 订单状态 / 节点模板全部改为**拖动排序列表**（按住拖动手柄上下拖动，松手保存）。
- 删除所有「排序值」手写数字输入框与表格列。
- 拖动排序即时保存（`dicts:reorder` / `statuses:reorder` / `templates:reorder`）。

## 十、数据迁移（V1.4 自动执行）

schema_version 4 → 5，启动自动迁移，保留数据：

- `customer` 增加 `sort_order`（初始化为 id，保持原顺序）；
- `material` 增加 `purchase_tax_included`（进货价含税标记）；
- `order_item` 增加 `purchase_tax_included`。

## 十一、验收标准增补

1. 左侧菜单有「微信群管理」，可跨客户查看/维护群与成员。
2. 客户卡片可拖动排序，刷新后顺序保持。
3. 客户卡片与编辑弹窗均可上传 Logo。
4. 物料/明细填写利润率后出货价自动计算；进货价与出货价可分别选择含税或不含税，金额与毛利正确。
5. 订单列表无订单编号列，展开行直接显示物料明细。
6. 订单详情进度为横向步骤条，无计划/实际/负责人，无跟进记录/附件入口，无上移下移。
7. 系统设置各字典通过拖动排序，无排序数字输入框。
8. 升级后原有数据完整保留，schema_version 自动升到 5。
