# PRD V1.9 变更说明（相对 V1.8.2）

- 版本：V1.9（2026-10-30）
- 依据：本轮 7 条需求（订单-供应商联动、采购合同图片、报价单命名/盖章、空数量隐藏、未税口径、订单数量与交期、订单卡片列顺序）。

## 1. 订单与供应商联动

- 订单明细每行新增「**供应商**」下拉（可搜索、可清空），用于指定该物料由哪家供应商提供。
- 从物料库选择物料时，若物料已关联供应商，会自动带出，仍可手改。
- 数据库：`order_item.supplier_id`；订单详情物料表新增「供应商」列。

## 2. 采购合同图片

- 订单详情新增「**采购合同**」卡片：可多选上传图片（png/jpg/jpeg/gif/bmp/webp），缩略图预览（点击放大）、可删除。
- 数据库：`order_attachment.kind`，采购合同标记为 `purchase_contract`，与普通订单文档分开。
- 普通「订单文档」列表不再混入采购合同。

## 3. 报价单去掉盖章处 + 命名规则

- Word 报价单签章区只保留「报价人 / 联系电话」，**删除（公司盖章处）**。
- 文件名改为：`客户简称 + 报价单 + _ + 日期`，日期用点分隔且不补零，例如 **`丹芬瑞报价单_2026.5.7.docx`**。
- 客户无简称时回退用客户全称。

## 4. 未填写需求数量时不输出相关字段

- 明细里数量为 0/空时：该行不输出数量、金额；
- 若所有行都没有数量：整列不输出「需求数量」「含税总额/不含税总额」，也不输出合计与人民币大写。
- 单价列仍保留（价格本身可独立填写）。

## 5. 未税价口径

- 报价单按订单行的价格口径判断：若所有行都是**未税售价**，表头显示「不含税单价（元）」「不含税总额（元）」，合计显示「合计（不含税总金额）」，金额 = 数量 × 未税单价。
- 否则按含税口径显示「含税单价/含税总额/合计（含税总金额）」。
- 合计金额按明细重新汇总（不再使用换算后的含税总额），保证与表头口径一致。

## 6. 订单数量与交期（二级菜单）

- 订单表单新增「**更多信息（订单数量 / 交期）**」折叠区（二级菜单）：
  - 订单数量（选填）
  - 交期（选填，即预计交货日期）
- 数据库：`orders.order_qty`。
- 报价单：填写了才在信息区显示「订单数量：N」「交期：YYYY-MM-DD」；未填写不显示。

## 7. 订单管理卡片物料列顺序

- 订单卡片内的物料表列顺序改为：**品牌 → 物料名称 → 料号规格 → 数量 → 含税金额**。

## 迁移与兼容

- schema 10 → 11（新增 `order_item.supplier_id`、`orders.order_qty`、`order_attachment.kind`）。
- 老数据自动兼容：供应商为空、订单数量为空、文档默认 `file`。
- 已在现有数据库副本上验证迁移成功。

## 测试

- 新增/更新：供应商明细与订单数量、采购合同 kind 过滤、报价单动态列/未税口径/数量缺失/文件名/去盖章、订单卡片列顺序、表单二级菜单、详情采购合同等。
- 共 **249** 个测试全部通过；三种报价单版式（含税/未税/无数量）经 LibreOffice 渲染检查正常。
