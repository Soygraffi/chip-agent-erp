# PRD V1.7.1 变更说明（相对 V1.7）

- 版本：V1.7.1（2026-10-29）
- 依据：用户提供 PPT 模板 `半导体元器件代理报价单模板A4横版3.pptx`，要求 Word 报价单按该模板排版。

## 变更

Word 报价单（新建订单页「导出报价单（Word）」）按 PPT 模板重排：

- **A4 横版**（29.7 × 21 cm）页面，左右页边距 2.4cm。
- 页眉：左侧公司中文名（深蓝加粗）+ 英文名；右侧「报 价 单」+「QUOTATION」；下方深蓝分隔线。
- 报价信息栏：报价日期、报价有效期（默认 30 天）；客户单位全称、对接人、联系电话；客户地址（选填）。
- **8 列明细表**：物料编码 / 物料名称 / 料号规格 / 品牌 / 需求数量 / 含税单价（元） / 含税总额（元） / 交期·备注（选填）；
  表头浅蓝底、整页宽度、跨页自动续页（表头重复）。
- **合计区**：合计（含税总金额）+ ¥ 金额；下一行「合计人民币（大写）」，自动转换中文大写（角分整补「整」）。
- 备注说明：使用系统设置 → 报价单中的条款（默认含 13% 增值税专票、交货周期、付款方式）。
- 签章区：报价人、联系电话、（公司盖章处）；页脚提示语。
- 数据来源：当前表单已填客户、联系人、地址、物料明细与总金额（无需先保存订单）。

## 测试

- 新增/更新：docx 结构（A4 横版、8 列表头、合计与大写、备注）、人民币大写转换（含角分整）。
- 共 **231** 个测试全部通过；示例文档经 LibreOffice 渲染检查版式正常。

## 验收标准

1. 新建订单填写明细后点「导出报价单（Word）」，生成 .docx 且为 A4 横版。
2. 版式包含公司抬头、报价信息、8 列明细、合计（含税总金额）、大写、备注说明、签章区。
3. 金额与明细与表单一致；不含税价自动换算含税单价。
