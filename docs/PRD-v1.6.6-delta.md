# PRD V1.6.6 变更说明（相对 V1.6.5）

- 版本：V1.6.6（2026-10-28）
- 依据：用户反馈「订单状态分布里数量为 0 的状态不要在圆表中显示」

## 变更

- 首页「订单状态分布」饼图**只展示数量 > 0 的状态**，数量为 0 的状态不再出现在扇区与图例中。
- 饼图下方的「状态说明」列表同样**只列出有订单的状态**，并注明该规则。
- 当所有状态都为 0（例如新库还没有订单）时，显示「暂无订单数据」占位，不绘制空饼图。
- 订单状态本身不删除、不影响统计口径；只是展示层过滤。

## 验收标准

1. 某状态订单数为 0 时，饼图中没有该扇区，图例/说明列表也没有该行。
2. 有订单的状态正常显示（数量、颜色、含义）。
3. 全部为 0 时显示「暂无订单数据」。
4. 测试全绿（222 个）。
