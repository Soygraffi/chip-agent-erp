# PRD V1.2 变更说明（相对 V1.1）

- 版本：V1.2（2026-10-28）
- 依据：用户反馈（客户字段精简、微信群管理、订单文档、字段可选、去掉币种/汇率/负责人）
- 关联：PRD-v1.1.md（其余未列出的需求保持不变）、data-model.md（已同步更新）

## 一、客户管理变更

### 1.1 字段精简（4.2.1）

**删除字段**：联系人、联系电话、邮箱、负责业务员、合作起始日期。

**保留字段**：

| 字段 | 必填 | 说明 |
|---|---|---|
| 客户全称 | 是 | 全局唯一（归一化判重，仅未删除客户） |
| 客户简称 | 否 | |
| 客户类型 | 否 | 字典项 |
| 地址 | 否 | |
| 重点客户 | 否 | 列表高亮 |
| 备注 | 否 | |

### 1.2 客户微信群（新增，4.2.5）

同一客户可维护多个微信群（如「商务交流群」「研发交流群」），每个群可维护成员：

| 对象 | 字段 | 说明 |
|---|---|---|
| 微信群 | 群名称（必填）、备注 | 一个客户 N 个群 |
| 群成员 | 群内微信号/ID（必填）、真实姓名、岗位、备注 | 微信群 → 成员 1:N |

- 客户列表新增「微信群数」列；客户详情页提供群与成员的增删改。
- 删除群时群成员一并删除（二次确认）。

## 二、订单管理变更

### 2.1 字段调整（4.3.1）

- **删除**：负责人、币种、汇率（含折人民币展示与汇率配置界面）。
- **改为选填**：订单日期、订单类型、订单状态、预计/实际交货日期、付款方式、备注、金额。
  - 未填写时界面统一显示「未填写」，不阻断保存。
  - 订单状态为空时：统计口径上视为「非终态（未结束）」；首页状态分布增加「未填写」扇区；
    订单列表/详情显示灰色「未填写」标签；Excel 导出输出「未填写」。
- **保留**：订单编号（自动/手录，全局唯一）、所属客户（必填）、订单总金额（自动汇总 + 可手改）、
  是否重点跟进、物料明细、进度节点。

### 2.2 沟通微信群（新增，4.3.5）

- 订单可从**该客户**的微信群中多选「沟通微信群」；跨客户群会被拒绝（校验：必须属于订单客户）。
- 订单详情展示所关联的微信群；Excel 导出增加「沟通微信群」列与独立 sheet。

### 2.3 订单文档（新增，4.3.6）

- 支持上传 **PDF / Word（doc、docx）/ 图片（png、jpg、jpeg、gif、bmp、webp）**。
- 文件复制进托管目录 `attachments/{orderId}/order/`，数据库记录原文件名、相对路径、大小、时间。
- 支持打开文件、打开所在目录、删除；单文件 ≤ 50MB。
- 删除订单时，订单文档与节点附件一并清理。
- 单订单详情 Excel 导出新增第 4 个 sheet「沟通微信群」（含群成员：微信号/姓名/岗位）。

### 2.4 进度节点（4.4）

- 节点移除「负责人」字段（与订单负责人一并删除）；其余不变（自动生成 10 节点、状态机、时间线、附件、跟进记录）。

## 三、首页看板（4.1）

- 「本月订单总金额」不再折人民币（单币种，直接汇总金额）。
- 状态分布饼图增加「未填写」扇区（订单状态为空的订单）。
- 「跟进中订单数」包含状态为空的订单（视为未结束）。

## 四、Excel 导入导出（4.5.1）

- 客户模板：客户全称* / 客户类型 / 客户简称 / 地址 / 备注（无联系人/电话列）。
- 订单模板：订单编号 / 客户全称* / 订单日期 / 订单类型 / 订单状态 / 总金额 / 预计交货日期 / 是否重点跟进 / 备注。
  - 仅「客户全称」必填且必须已存在；其余留空即「未填写」。
- 订单列表导出列：订单编号、客户、类型、状态（未填写）、金额、订单日期、预计交期、重点跟进、逾期天数、沟通微信群。
- 单订单详情导出 sheet：订单信息 / 物料明细 / 进度节点 / 沟通微信群。

## 五、系统设置（4.6）

- 移除「汇率」配置页与币种字典入口（币种相关数据保留在库中但不再使用）。
- 其余（客户类型/订单类型/付款方式/订单状态/节点模板/编号规则/存储设置）不变。

## 六、数据迁移（V1.2 自动执行）

- schema_version 2 → 3，应用启动时自动迁移，**保留已有客户/订单/节点数据**：
  - 重建 customer 表（移除联系方式等列）；
  - 重建 orders 表（order_date / status_id 允许为空，移除 currency_id / exchange_rate / owner）；
  - 重建 order_node 表（移除 owner）；
  - 新增 customer_wechat_group、wechat_member、order_attachment、order_wechat_group 四张表。
- 旧字段数据（联系方式、币种、负责人）在迁移中丢弃（用户已确认不需要）。

## 七、验收标准增补（对应第九章）

1. 客户不再显示联系人/电话/邮箱/负责业务员/合作起始日期；新建客户仅需客户全称。
2. 一个客户可添加多个微信群；每群可维护成员的微信号、真实姓名、岗位并增删改。
3. 订单可上传 PDF/Word/图片并在详情页打开；删除订单时文档一并删除。
4. 订单日期/类型/状态留空可保存，界面显示「未填写」，统计与导出口径一致。
5. 订单可多选该客户的沟通微信群，跨客户群被拒绝；详情与导出可见。
6. 订单/节点不再出现负责人；订单不再有币种与汇率；首页金额为单币种汇总。
7. 升级后原有数据完整保留（客户/订单/节点），schema_version 自动升到 3。
