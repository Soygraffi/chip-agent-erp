# PRD V1.6.4 修复说明（相对 V1.6.3）

- 版本：V1.6.4（2026-10-28）
- 问题：V1.6.3 为修复“第一个节点点不动”，把进度条换成了自绘样式，外观与原设计不一致（用户反馈“变丑了”）。

## 修复

- 恢复原有的 antd `Steps` 步骤条外观（圆点 + 标题 + 状态标签，与之前一致）。
- 保持可点击：在步骤条上叠加**透明点击层**，按步骤等宽覆盖，
  点击任意步骤（含当前步骤「需求沟通」）都会打开「更新进度」；
  透明层不影响原有渲染，仅在悬停时显示极淡高亮。
- 订单管理卡片与订单详情页均使用该实现。

## 验收标准

1. 进度条外观与之前版本一致（antd 步骤条样式）。
2. 点击任意步骤（尤其是第一个）可打开更新进度弹窗。
3. 测试全绿（219 个）。
