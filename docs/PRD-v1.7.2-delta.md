# PRD V1.7.2 修复说明（相对 V1.7.1）

- 版本：V1.7.2（2026-10-29）
- 问题：导出的 Word 报价单「整体偏右/出界、不好看」，且中文公司名缺失。

## 原因

1. **表格超出可打印宽度**：A4 横版可用宽度为 16838 − 2×1360 = **14118 twips**，
   而明细表/合计表宽度写成了 15158 twips，右侧超出约 1.8cm，视觉上整体“歪向右”。
2. **中文公司名缺失**：报价单抬头读取 `setting.company_name`，老数据库该值为空，
   于是头部只剩英文名（模板中的中文大字标题没有出现）。

## 修复

- 明细表 8 列宽度合计改为 **14114 twips**（与可打印宽度一致）；合计表/大写行/签章制表位同步为 14114，
  左右页边距对称，不再出界。
- 新增迁移（schema 9 → 10）：`company_name` 为空时自动写入
  「湖北长江光电子信息产业供应链有限公司」；导出逻辑也保留同名兜底。
- 「系统设置 → 报价单」新增**报价人 / 联系电话**两个字段，导出时自动填入签章区
  （此前只能显示下划线）。
- 表格宽度、公司名、签章信息三项均已用 LibreOffice 渲染验证。

## 验收标准

1. 导出的 Word 报价单左右边距对称，表格不超出页面。
2. 抬头显示中文公司名（默认湖北长江光电子信息产业供应链有限公司）。
3. 设置报价人/电话后，签章区自动带出。
4. 测试全绿（231 个）；升级后 schema_version = 10。
